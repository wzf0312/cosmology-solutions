## 内容

- [`宇宙学习题解.pdf`](./宇宙学习题解.pdf)：膨胀宇宙的运动学和动力学。

## 说明

这是由中科院理论所皮石研究员翻译, 维亚切斯拉夫·穆哈诺夫（Viatcheslav Mukhanov）先生著的《宇宙学的物理基础》（Physical Foundations of Cosmology）的部分习题解答。此书是我在科大上宇宙学的课所使用的课本, 课程由蔡一夫老师和罗文涛老师主讲。当时我虽有兴趣, 但奈何囫囵吞枣（也可能是因为课程开始于下午第一节, 容易让人睡午觉）, 没有完全理解课程内容。在看到此书出了中文版后便第一时间加入购物车, 等到回家重新精读一番。静下心来仔细推敲后才发现其中内容真如安德烈·林德(Andrei Linde)的序言所说“就像一幅高水平的油画一样, 本书由许多层次组成。它可以用作新生代研究人员的宇宙学导论, 也包括了许多即使对本领域的顶级专家也十分有用的信息。(As in a good painting, this book consists of many layers. It can serve as an introduction to cosmology for the new generation of researchers, but it also contains a lot of information which can be very useful even for the best experts in this subject.)”本人才疏学浅, 希望能完成这本著作的阅读和完成所有习题, 部分内容参考了科大前几届学长留下的习题答案。如需源文件或勘误，欢迎提交 Issue 或 Pull Request。
